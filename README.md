# Curry Voyage — Spice Route Kitchen

A harbour-stall cooking game on the old spice route. Travellers pin their
tickets to the order board; you run the route behind the counter:

1. **Toast the spice** — click a raw blend (Garam Masala, Turmeric Gold or
   Rendang Dark) and watch the dry pan. Take it out in the ready window or
   it burns.
2. **Load the simmer pot** — a protein, the toasted spice and coconut milk,
   then let it simmer until rich. Scorched pots get scrubbed, not served.
3. **Mind the griddle** — roti dough needs its own timer while the curry rests.
4. **Plate it exactly** — curry, the right side, the garnish set and the
   exact heat (chilli-flake pinches 0–3) the ticket asks for, then SERVE.

Late travellers walk away; three strikes end the shift. Tips reward swift
service, and the rush thickens as the 3-minute shift runs down — the whole
game is planning the order of pan, pot and griddle so nothing waits burnt
while something else waits raw.

**Controls:** mouse clicks on stations and ingredient bins, or keyboard —
1–3 spices, 4–7 proteins, 8 coconut milk, 9 rice, 0 roti dough, Q/W
garnishes, E chilli flakes, Enter serve, Backspace bin the plate, R new shift.

Open `game/index.html` in a desktop browser to play (no network needed).
Run `node main.ts` with `MAKEFUN_OUTPUT_DIR` set to package the entry.
